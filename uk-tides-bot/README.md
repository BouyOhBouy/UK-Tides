# 🌊 UK Tides Instagram Bot

Automatically posts daily UK tide times to Instagram every morning at 07:00 UTC.

## Data Source
Environment Agency Tide Gauge API — free, no API key required, updated every 15 minutes.

## Stations Covered
Aberdeen, Liverpool, Cardiff, Avonmouth, Portsmouth, Bournemouth, Barmouth, Heysham, Whitby, Immingham

## Setup
1. Add `INSTA_USERNAME` and `INSTA_PASSWORD` as GitHub repository secrets
2. Push this repo — GitHub Actions handles the rest

## Manual Run
Go to Actions tab → "Daily UK Tides Post" → "Run workflow"
